Cloudflare Access rejected the service token for argo.internal.beta-cloudspot.io

The request was redirected to the Access login page. Check that the Access application for this host has a Service Auth policy for this token.

Argo permission

The pr-dashboard account can’t read logs in Production

Argo returned 403 for logs. Add this line to policy.csv in infrastructure/apps/argo/values_prd.yaml:

p, role:pr-dashboard, logs, get, default/*, allow
